# DSA From Scratch

This repo is my personal place to implement data structures in C++ so I actually understand how they work — how memory behaves, why some operations are fast and others are slow, and how things change when you tweak implementations.

I write small, commented experiments and notes as I go. No polished tutorials — just code, thoughts, and the occasional diagram I drop into the comments.

If you're reading this: feel free to poke at the code, break it, and see what happens. That's how I learn.
